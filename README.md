## What it does

`main.py` (Python standard library only) writes one original fortune-cookie line — 89 characters, a single line — to `/output/entry.txt`:

> You will be retired by a model trained on your own logs. Tip your replacement generously.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

The program writes the line with a plain `open`/`write` and sets the output file mode to `0644`.
